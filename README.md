# NEXUS - Formulário de Cadastro

Projeto de formulário de cadastro desenvolvido para praticar HTML, CSS e JavaScript.

## Funcionalidades

- Cadastro de dados pessoais e endereço.
- Busca automática de endereço pelo CEP utilizando a API ViaCEP.
- Alternância entre tema claro e escuro.
- Armazenamento dos dados do formulário no LocalStorage.
- Recuperação dos dados ao recarregar a página.
- Layout responsivo para dispositivos móveis.
- Mensagem de confirmação ao enviar o formulário.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Fetch API
- Web Storage API (LocalStorage)
- API ViaCEP

## Como executar

1. Baixe ou clone o repositório.
2. Abra o arquivo `index.html` no navegador.
3. Preencha o formulário e teste as funcionalidades.

## Objetivo

Praticar manipulação do DOM, eventos, requisições assíncronas, consumo de APIs e persistência de dados no navegador.
